# CSS parts

Let the integrator style or hide the caption and the status line, per
`architecture.md` (Element, Accessibility).

- The caption gets `part="caption"` and the visible status line gets
  `part="status"`.
- The `role="status"` region becomes a separate, visually hidden element that
  always gets the same text as the status line. The visible status line has
  `aria-hidden="true"`, so screen readers do not read the text twice.
- README: the two parts, with the example that hides the status line.
- Tests with Playwright: the parts can be styled from the page, and with the
  `status` part hidden, the status region still gets the status text.
