# Mode fallback

Move the fallback mode into `allowedModes` in `src/settings.ts`. The element's
behavior does not change.

- `allowedModes` returns the first of all modes (`hold`, `review`) when the
  value names none, so `#allowedListenModes` and `#allowedSubmitModes` become
  one line each.
- Tests: the unit test for a value with no known mode expects the fallback
  instead of an empty list; all other tests pass unchanged.
