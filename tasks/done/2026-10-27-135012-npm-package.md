# npm package

Make dicta-js ready to publish to npm, per `architecture.md` (Delivery).

- `package.json`: remove `"private": true`; add `description`, `keywords` and
  `repository`; add a `prepublishOnly` script that builds a clean `dist/`, so no
  stale file is published.
- Check with `npm pack --dry-run` that the package holds only `dist/`,
  `README.md`, `LICENSE` and `package.json`.
- Check by hand, in throwaway apps outside the repo, that Vite (dev server and
  build) and webpack bundle the packed package and serve `audio/worklet.js` at
  the URL the element asks for. Write any setup they need in `docs/usage.md`.
- `docs/usage.md`: a section on installing from npm and importing it, next to
  loading from dicta-server.
- `docs/releasing.md`: a step to publish to npm after the GitHub release, from
  the release commit; "Where releases go" names npm.
