# Example page

Add an example page to try dicta-js by hand against a running dicta-server, with
a real microphone. Not part of the published package.

- `example/index.html`: one `<dicta-input>` with text and voice, and a list of
  the `dicta-text` events it sends. The server URL comes from the `server` query
  parameter, so no file has to be edited; the voice mode from `voice-mode`.
- No token: it is meant for a dicta-server with `ALLOW_UNAUTHENTICATED=true`.
- `npm run example` builds and serves the page and `dist/` on port 4174, or on
  `PORT`. The microphone needs `localhost` or HTTPS, for example through a
  reverse proxy.
- No automated tests: the page only uses what the browser tests cover.
