# Worklet in one file

`audio/worklet.js` imports `./converter.js`, which breaks when a bundler copies
or inlines the worklet. Per `architecture.md` (Delivery), the worklet imports
nothing.

- Move `PcmConverter` and its constants from `audio/converter.ts` into
  `audio/worklet.ts` and remove `converter.ts`.
- The converter unit test imports `worklet.ts`. It stubs the AudioWorklet
  globals the module uses when it loads.
