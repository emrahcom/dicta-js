# Voice review

Add `voice-submit-modes` with `review` and `auto`, per `architecture.md`
(Element, Text input, Voice input). The user switch comes in a later task; until
then the first allowed mode is used.

- `voice-submit-modes`: the allowed modes, the first one the default,
  `review auto` without the attribute. Unknown words are ignored; with no valid
  mode left, `review` is used. Without text input it is always `auto`.
- `auto`: as today, with the interim text in the caption.
- `review`: the interim text is shown in the field at the cursor, replacing any
  selected text, with a space between it and the text next to it. The final
  replaces it and the cursor moves after it. An empty final removes it. While
  the interim text is shown, the field is read-only and Enter does not submit. A
  close or an error removes it.
- `dicta-text` gets `input: "mixed"`: the element tracks whether the user typed
  into the field and whether a voice final was put into it. Both are reset when
  the field is submitted or becomes empty.
- Example page: `voice-submit-modes` from the query string. README: the
  attribute and `mixed`.
- Tests with Playwright: the default, `auto` with the caption, voice-only always
  `auto`, review at the cursor between typed text, a selection replaced, the
  final replacing the interim text, an empty final, read-only and no submit
  during the interim text, several finals in a `toggle` session, and `text`,
  `voice` and `mixed` on submit.
