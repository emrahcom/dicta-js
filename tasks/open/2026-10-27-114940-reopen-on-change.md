# Reopen the connection when server or lang changes

When listening starts, reopen the connection if `server` or `lang` differs from
what it was opened with, per `architecture.md` (Connection).

- `#start` remembers the `server` and `lang` of the connection it opens. When an
  open connection has other values, it closes that connection and opens a new
  one.
- Tests (browser): the fake server records each connection's URL. After an
  utterance, changing `lang` makes the next one open a new connection with the
  new `lang` and closes the old one; without a change, the next utterance uses
  the same connection.
