# Review switch

Let the user choose between `review` and `auto`, per `architecture.md` (Element,
Voice input).

- With both submit modes allowed and text input on, a native checkbox with the
  label "Review before sending", checked for `review`. It has
  `part="voice-submit-mode"` and is disabled while the element listens.
- The user's choice is stored in `localStorage` under `dicta-voice-submit-mode`,
  like the listen mode: a stored mode that is not allowed is ignored, and
  storage that fails is ignored too.
- README: the switch.
- Tests with Playwright: shown only with both modes and text input, the default,
  switching to `auto` changes where the text goes, the choice kept after a
  reload, a stored mode no longer allowed, disabled while listening and the
  part.
