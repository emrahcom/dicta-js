# Early getToken

Keep a `getToken` the page sets before the element is defined, per
`architecture.md` (Element: `getToken`).

- `getToken` is compiled as a class field today, so defining the element
  overwrites a `getToken` set on it before `customElements.define` ran, as a
  framework, a classic script or a lazy-loaded module may do. The element then
  connects without a token.
- Declare it without a field (`declare getToken`), so nothing is emitted for it
  and a value set earlier stays.
- Tests with Playwright: a `getToken` set before the element is defined, and one
  set after, each send their token to the server in the `Sec-WebSocket-Protocol`
  header.
