# Text input

Add the `<dicta-input>` element with text input only, per `architecture.md`
(Element, Text input). Voice comes in later tasks.

- Element: defined on import, with a shadow root. `inputs` and `placeholder` as
  in the spec; the text field is shown only when `inputs` includes `text`.
- Text field: grows from one line up to 5 lines, then scrolls. Enter submits,
  Shift+Enter adds a new line. Trimmed, empty text not submitted, cleared after
  a submission, which sends `dicta-text` with `{ text, input: "text" }`.
- Tests: Playwright in Chromium, Firefox and WebKit, against the built module.
  Node's test runner stays for logic without a DOM.
- Add the browser tests to the verification commands in `CLAUDE.md`.
