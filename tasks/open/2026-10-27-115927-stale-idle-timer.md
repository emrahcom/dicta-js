# Stale session idle timer

A toggle session ended during speech leaves a 5 minute idle timer running, which
can later end another utterance. Per `architecture.md` (Listening, `toggle`),
the 5 minutes belong to the session.

- In `onFrame`, restart the idle timer only while that session still listens:
  its detector is the current one and the element is listening.
- Test (browser): end a toggle session with a press during speech, start a hold
  utterance and move the clock 5 minutes; it is still listening.
