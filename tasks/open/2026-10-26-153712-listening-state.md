# Listening state

Add the custom state `listening`, per `architecture.md` (Element).

- The element has the custom state `listening` exactly while the microphone
  button has `aria-pressed="true"`, set through `ElementInternals.states`.
- README: styling the pressed button with
  `dicta-input:state(listening)::part(button)`.
- Tests with Playwright: the state is set while listening and removed after it,
  also after a failure, and the page can style the pressed button with it.
