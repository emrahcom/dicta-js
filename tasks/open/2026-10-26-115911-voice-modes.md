# Voice modes

Replace `voice-mode` with `voice-modes` and let the user switch the mode, per
`architecture.md` (Element, Voice input).

- `voice-modes`: the allowed modes, the first one the default, `hold toggle`
  without the attribute. Unknown words are ignored; with no valid mode left,
  `hold` is used. `voice-mode` is removed.
- With both modes allowed, a native select next to the button, named "Voice
  mode", with "Hold to talk" and "Hands-free". It is disabled while the element
  listens.
- The user's choice is stored in `localStorage`. A stored mode that is not
  allowed is ignored. Storage that fails, as in some private windows, is ignored
  too.
- Example page and README: `voice-modes` instead of `voice-mode`. The README
  also advises allowing `toggle`, for users who cannot hold a button.
- Tests with Playwright: the default and the order, one mode without a select,
  switching, the choice kept after a reload, a stored mode no longer allowed,
  and the select disabled while listening. Existing tests move to `voice-modes`.
