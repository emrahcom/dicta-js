# Source cleanups

Code quality fixes from the review of 2026-11-20, with no change in behaviour.
The element's attributes, properties, events, CSS parts and strings stay as they
are.

- Exports nothing imports lose `export`: `ConnectionEvents` in
  `src/connection.ts`, `Detection` in `src/audio/detector.ts`, and
  `SettingsInput`, `ListenMode` and `SubmitMode` in `src/settings.ts`.
- `src/input.ts`:
  - one small function tells whether a key presses a button (space or Enter), in
    place of two copies;
  - the status text "Listening" is one constant, used where it is written and
    where it is read;
  - `#start` gets a `#connect()` that keeps the open connection or opens a new
    one, so `#start` reads as its steps;
  - the microphone button is built in its own function, out of the constructor;
  - the comment over 80 characters is rewrapped.
- `src/audio/worklet.ts`: the comment on the audio format sits with the code it
  describes, or joins the file's header, not as a second header.

Tests: the existing tests pass unchanged.

Check: `npm run check`, `npm run lint`, `npm run test`, `npm run test:browser`
and `npm run build` pass.
