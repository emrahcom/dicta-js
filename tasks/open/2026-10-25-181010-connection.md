# Connection

Add the WebSocket client to dicta-server, per `architecture.md` (Connection) and
`contract-protocol.md` in `dicta-server`. Not yet used by the element.

- Opens `<server>/dicta/v1/listen` with `lang` when set, and the token from
  `getToken` in the subprotocol header after `dicta`.
- Audio frames and `end` given before `ready` are kept and sent after it, in
  order and in the same frames.
- Reports interim and final transcripts, and reports a close or an error once,
  with the close code. Unknown message types are ignored.
- Without `getToken`, it connects with only `dicta` in the subprotocol header. A
  failing `getToken` is reported like a failed connection.
- Tests with Node's test runner against a local WebSocket server (`ws` as a dev
  dependency), using Node's global `WebSocket`, which follows the browser API.
