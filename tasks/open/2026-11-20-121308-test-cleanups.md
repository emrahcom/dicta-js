# Test cleanups

Test fixes from the code quality review of 2026-11-20. The tests check the same
behaviour as before, with less repetition, in the file a reader would look in.

- `test/browser/voice.spec.ts`:
  - its tests are grouped by kind, such as hold, toggle, review, shortcut and
    connection, or the shortcut and connection tests move to their own spec
    files;
  - its helpers sit together at the top;
  - the two tests of the shortcut in the title with both inputs are one;
  - the tests that hold and release the button by hand use `holdAndRelease`,
    which also takes the connection to wait on;
  - the looped test with branches inside becomes two plain tests;
  - the free-standing comment on the fake microphone goes; `page.ts` says it.
- `test/browser/modes.spec.ts`: the three scenarios written once for the listen
  mode and once for the review switch are one table each.
- The test of the Send button's part moves to `test/browser/style.spec.ts`.
- `test/connection.test.ts`: the two tests that differ only in `getToken` are
  one table, and its waits use one `sleep`.

Check: `npm run check`, `npm run lint`, `npm run test` and
`npm run test:browser` pass, with no checked behaviour lost.
