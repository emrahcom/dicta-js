# Fake microphone

Give the browser tests the same fake microphone in Chromium, Firefox and WebKit,
so the voice tests run in all three supported browsers (`architecture.md`,
Delivery). The element does not change.

- `test/browser/page.ts` replaces `navigator.mediaDevices.getUserMedia` before
  the page loads with a stream made in the page: a 300 Hz tone, 1 s on and 2 s
  off, in a loop. The on and off steps are scheduled on the AudioContext clock,
  so a test with a fake page clock does not stop them. Tests that replace
  `getUserMedia` themselves still do so.
- `playwright.config.ts` drops the generated WAV file and the fake media flags
  and prefs, which the page microphone replaces.
- Firefox knows only PulseAudio. When `/usr/lib/x86_64-linux-gnu/apulse` exists,
  the Firefox project starts with that folder in `LD_LIBRARY_PATH`, so it plays
  and processes audio through ALSA without a sound server.
- Tests: the existing browser tests pass in Chromium, Firefox and WebKit on this
  machine.
